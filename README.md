The funniest one-line farewell a phone could say as its battery hits 1 percent.

`main.ts` writes a single line to `/output/entry.txt`:

> I'm at 1%, so I'm spending it downloading the update you postponed 38 times. Good luck.

Run it with `node main.ts` (Node 22+).
